# SOFTIE GOODS — Vintage Thrift Landing Page

Landing page responsif dan interaktif bertema vintage/aesthetic untuk toko thrift online **SOFTIE GOODS**. Dirancang menggunakan pendekatan formula marketing **AIDA** (Attention, Interest, Desire, Action) dan dioptimalkan khusus untuk tampilan mobile.

## ✨ Fitur Utama
- **Formula Marketing AIDA**: Dirancang runtut mulai dari hero banner, keunggulan/benefit, katalog produk, alasan membeli, fasilitas belanja, hingga call-to-action.
- **Interaktivitas Penuh**:
  - ⚡ **Flash Sale Urgency Timer**: Countdown waktu mundur *real-time*.
  - 🎁 **Voucher Diskon**: Tombol klaim & salin kode voucher diskon dengan efek *confetti blast*.
  - 🏷️ **Filter Kategori Produk**: Filter dinamis (Semua, Hemat ≤ Rp45k, Premium Look, dan Favorit).
  - ❤️ **Wishlist / Favorit**: Simpan produk favorit langsung ke *localStorage*.
  - 🔍 **Detail Modal & Auto-Text WhatsApp**: Pop-up spesifikasi tas lengkap dengan tombol WhatsApp otomatis terisi pesan pesanan.
  - ❓ **FAQ Accordion**: Pertanyaan seputar pencucian/laundry, stok unik, dan keamanan pengiriman.
  - 📢 **Live Social Proof Ticker**: Notifikasi dinamis aktivitas transaksi pembeli.
  - 🖼️ **Image Lightbox**: Tinjauan foto resolusi tinggi dengan swipe & keyboard navigation.
- **Call-to-Action (CTA)**: Terhubung langsung ke WhatsApp Admin & Shopee Official.

## 🚀 Menjalankan Secara Lokal
Cukup buka file `index.html` langsung di browser atau gunakan server lokal:
```bash
python3 -m http.server 8000
```
Buka browser di `http://localhost:8000`.
